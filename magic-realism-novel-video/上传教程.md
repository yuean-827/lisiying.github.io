# 上传到 GitHub 教程

本目录就是**一个完整的 GitHub 仓库**，直接整个传上去即可。下面给两种方式，任选一种。

---

## 一、要上传哪些文件？

**答案：`magic-realism-novel-video` 这个文件夹里的全部内容，一个都别少。**

```
magic-realism-novel-video/
├── .nojekyll                              ← 必须传（空文件，让 Pages 别用 Jekyll）
├── .gitignore                             ← 建议传
├── README.md                              ← 必须传
├── index.html                             ← 必须传（展示页）
├── assets/
│   ├── poster.jpg                         ← 必须传（视频封面）
│   ├── stills/01.jpg ~ 09.jpg             ← 必须传（九张剧照）
│   └── video/bainiangudu.mp4              ← 必须传（网页版成片 15MB）
└── skills/magic-realism-novel-video/
    ├── SKILL.md                           ← 必须传（技能主说明）
    ├── reference.md                       ← 必须传
    ├── scripts/
    │   ├── gen_script.py                  ← 必须传
    │   ├── gen_tts.py                     ← 必须传
    │   └── build_video.py                 ← 必须传
```

## 二、方式 A：网页拖拽上传（最简单，零命令，推荐）

### 第 1 步：新建仓库
1. 登录 GitHub → 右上角 `+` → **New repository**
2. 填写：
   - **Repository name**：`magic-realism-novel-video`
   - **Description**（可选）：`《新媒体交互设计》作业1 — 百年孤独名著介绍视频生成 Skill`
   - 可见性选 **Public**（Pages 免费版必须公开）
   - **不要**勾选 Add README / .gitignore / license（避免冲突）
3. 点 **Create repository**

### 第 2 步：上传文件
1. 在新仓库页面点 **uploading an existing file**（或地址栏直接访问
   `https://github.com/你的用户名/magic-realism-novel-video/upload/main`）
2. 打开本地的 `magic-realism-novel-video` 文件夹，**全选里面的内容**（Ctrl+A），
   一起拖进浏览器上传区。
3. **关键坑**：拖拽**不会自动上传子文件夹里的内容**时，就分几次传——
   先全部拖进去一次；若发现 `assets`、`skills` 是空的，就单独进入 `assets` 文件夹
   全选拖一次，再进 `skills/magic-realism-novel-video` 全选拖一次。
   > GitHub 网页版**支持**拖拽整个文件夹并保留目录结构，放心拖；
   > 只要拖的是「文件夹」而不是「文件夹里的文件」，层级就不会丢。
4. 底部 **Commit message** 填 `init: 百年孤独名著介绍视频 Skill`，点 **Commit changes**

### 第 3 步：确认 `.nojekyll` 也在
上传后仓库根目录应能看到 `.nojekyll`。如果网页上传时被过滤（以点开头的隐藏文件），
用「第 4 步」的 Add file → Create new file，文件名输入 `.nojekyll`，内容留空，提交即可。

### 第 4 步：开启 GitHub Pages
1. 仓库 → **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
4. 等 1~2 分钟，刷新页面，顶部会出现网址：

```
https://你的用户名.github.io/magic-realism-novel-video/
```

打开即是作品展示页，视频可在线播放。

## 三、方式 B：命令行推送（结构最不容易出错）

先装好 Git（已装可跳过），然后在 **Git Bash** 里按顺序执行：

```bash
# 1. 进入仓库目录（注意路径里的 \ 在 Git Bash 要写成 /）
cd "C:/Users/hp/WorkBuddy/2026-10-09-20-20-28/magic-realism-novel-video"

# 2. 初始化并提交
git init
git add -A
git commit -m "init: 百年孤独名著介绍视频 Skill"

# 3. 关联远程仓库（用户名换成你自己的）
git branch -M main
git remote add origin https://github.com/你的用户名/magic-realism-novel-video.git

# 4. 推送
git push -u origin main
```

推送时若要求登录：用户名填 GitHub 用户名，密码**不能填账号密码**，要填
**Personal Access Token**（Settings → Developer settings → Personal access tokens →
Tokens(classic) → Generate new token → 勾选 `repo` → 复制生成的 `ghp_...`）。

推送完成后，照上面**方式 A 的第 4 步**开启 Pages 即可。

> 更省事的替代：先按方式 A 建好空仓库并开启 Pages，再用方式 B 推送，两步都不冲突。

## 四、常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 页面 404 | Pages 还没构建完 / 分支选错 | 等 1~2 分钟；确认 Branch=`main`、目录=`/ (root)` |
| 页面能开但样式全乱 | `assets/` 没传全 | 检查 `assets/stills/` 是否有 9 张 jpg |
| 视频不播放 | `bainiangudu.mp4` 没传或路径不对 | 确认 `assets/video/bainiangudu.mp4` 大小为 15MB |
| 中文文件名乱码 | 网页上传时编码问题 | 本仓库文件名**已全部改为英文**，不会出现此问题 |
| push 被拒 `file is 100.00 MB` | 传了桌面上的原始 98MB 视频 | 不要传原片，只用仓库里的 15MB 网页版 |
| 想改仓库名 | 随时可改 | Settings → Repository name，Pages 网址会同步变化 |
