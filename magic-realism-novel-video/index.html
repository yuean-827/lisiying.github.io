给一个书名
自动产出一支名著介绍视频

这不是一支孤立的视频，而是一套可复用的能力包：输入书名，自动完成剧本创作、旁白配音、 配图生成、动态视频生成与成片合成的全过程。作品《百年孤独》是它的一次实跑验证。

书名 《百年孤独》 画幅 9:16 竖屏 时长 155.5 秒 分辨率 1080 × 1920 段落 9 段
01 / WORK

作品：《百年孤独：马孔多的一场大雨》

从「多年以后，面对行刑队」的开篇，到飓风抹去马孔多，用统一的魔幻现实主义油画风格串起七代人的命运。

  • 片名百年孤独：马孔多的一场大雨
  • 结构片头 3s ＋ 正文 9 段 ＋ 片尾 3.2s
  • 旁白中文男声，语速 −5%
  • 画面9 张 9:16 配图 → 逐段转为 5 秒动态素材，慢放对齐旁白
  • 字幕ASS 楷体，底部居中带描边
  • 转场段间叠化 0.5 秒（xfade）
  • 统一画风拉美魔幻现实主义油画风格，厚涂笔触，暗金与青灰配色
全片不串味的两个关键。 一是每段画面描述末尾的风格后缀逐字一致； 二是布恩迪亚家族成员的外形描述先写死、再复制进每一段提示词。 这两条只要松一条，九张图就会变成九种画风。

03 / THE SKILL

Skill 的六个要素

技能名 magic-realism-novel-video。触发清楚、流程明确、校验可执行——而不是把说明写得多。

1

标题和描述

一句话说清用途：给一个书名，自动产出一支 9:16 竖屏名著介绍视频。让 Agent 能一眼判断该不该用它。

2

When to Use

写具体场景，不写泛。包括「用《X》做一条视频」这类口语触发，也明确列出不该用的情形。

3

Capabilities

能做什么：出剧本、合成旁白、生成配图、转动态视频、烧字幕合成片。同时框定能力边界。

4

Process

八步流程，每步都有明确产出文件。第 2 步强制停下来给用户确认，防止一步跑到底全盘皆错。

5

Output Format

写死交付物清单与路径，避免 Agent 输出一堆散乱解释却不落盘。

6

Examples

给《百年孤独》和《老人与海》两个例子，说明换书时哪些部分保留、哪些部分替换。

调用方式

# 1. 准备项目配置（书名、画风、各段内容）
python scripts/gen_script.py \
  --project templates/project.example.json \
  --out ./百年孤独

# 2. 合成旁白
python scripts/gen_tts.py \
  --project templates/project.example.json \
  --out ./百年孤独

# 3. 生成配图与动态素材后，合成成片

04 / PIPELINE

完整制作流程

从书名到成片，八个阶段，每一步都有落盘产物，可中断、可复核、可重跑。

① 剧本
由书名生成标题、各段 【阶段】:【情节】、固定人物形象、画面描述与旁白文案，产出 script.md 与 分镜.md。这一步必须停下来给用户确认。
② 语音
用 edge-tts 逐段合成中文旁白，输出 音频/NN.mp3。同时记录每段时长——它是后续所有画面时长的唯一依据。
③ 配图
按各段画面描述生成 9:16 竖版配图，每段末尾拼上完全相同的风格后缀，输出到 图片/。
④ 去水印
生成式图片右下角带水印。用「上方克隆纹理 + 中心裁剪 9:16」的方式清除，成品存入 图片916/。
⑤ 生视频
以配图为首帧逐段生成 5 秒竖版动态素材，输出到 视频/。先只做第 1 段，确认风格后再批量，避免全废。
⑥ 合成
逐段：素材慢放对齐旁白时长 → 裁除底部水印 → 烧录 ASS 字幕。再用 xfade 叠化串联全部段落，acrossfade 串联音轨，加上片头片尾。
⑦ 自检
抽帧生成九宫格预览图，逐条核对检查清单：画风是否统一、人物是否对得上、字幕是否与旁白一致、水印是否清干净。
05 / NOTES

踩坑记录

这些是实际跑通一遍之后才发现的，已全部写进 reference.md，下次不用再踩。

✕旁白比画面长得多

计划 5 秒一段，实际旁白每段更长。解决办法是让素材慢放 1.6~2.0 倍来填满，而不是硬切音频——慢放之后反而更有纪录片的质感。

✕中文连续文本不自动换行

libass 对连续中文不会断行，WrapStyle: 0 也无效，字幕会直接顶出画面。唯一可靠的办法是在 ASS 里手动写 \N 断点。

✕delogo 去视频水印会留拖影

delogo 从四周边界插值，在有笔触纹理的画面上会留下明显竖向条纹。改成裁掉底部 110px 再放大回原尺寸，等效放大 6%，完全无伪影。

✕装 ffmpeg 卡在 GitHub

pip install imageio-ffmpeg 会去 GitHub 拉二进制包，国内经常卡死。可靠做法是从清华 PyPI 镜像直接下载 wheel 文件，再本地安装。
