# 外国名著介绍视频生成器（魔幻现实主义版）

Given a book title, automatically produce a 9:16 vertical explainer video
(script → narration → stills → motion clips → assembled MP4).
Verified with《百年孤独》：155 秒 / 1080×1920 / 9 段正文。

## When to Use

Use this skill when:

- 用户给出一个外国名著书名（尤其拉美/欧美文学），要求做「名著介绍」「好书推荐」类竖屏短视频。
- 用户点名 `/magic-realism-novel-video <书名>`，或说「用《百年孤独》那套流程」。
- 用户已有剧本或配图，只想跑流程中的某一段（此时只执行对应阶段）。

Do NOT use this skill when:

- 目标不是名著介绍（如产品广告、口播剪辑、B-roll 拼贴）。
- 用户要中国古典题材（请改用工笔画风格版本 classic-novel-video）。

## Capabilities

- 生成 9 段式剧本：标题、阶段、情节、画面描述、旁白文案。
- 合成中文旁白音频（逐段 MP3，edge-tts 免费）。
- 生成 9:16 竖版配图，锁定统一画风（拉美魔幻现实主义油画风）与人物形象。
- 把配图转成 5 秒动态视频片段（图生视频）。
- 生成 ASS 字幕、烧录、叠化串联、输出成片 MP4。

## Constraints（硬性约束，违反必然串味）

1. **风格后缀逐字一致**：每段画面描述末尾必须使用完全相同的画风后缀字符串。
   本版本默认：`拉美魔幻现实主义油画风格，厚涂笔触，暗金与青灰配色，烛光与雨雾气氛`。
2. **人物形象先定后写**：把人物外形描述写死在 project.json 的 `characters` 里，
   再整段复制进每一段画面提示词。
3. **批量前先试样**：生成视频前必须先只跑第 1 段，确认风格后再批量。
4. **旁白决定时长**：段落时长 = 该段旁白时长 + 0.5s 留白，不预设固定秒数。
5. **素材自带水印**：生成式视频产物右下角带「视频由AI生成」水印，合成时必须
   裁除底部 110px 再放大回原尺寸（不要用 delogo，会留拖影）。
6. **素材未落地不进入下一阶段**：每阶段产物必须落盘并能列出文件后，才允许继续。

## Process

1. **确认输入**：拿到书名；若用户未给书名，先问一句再开工。
2. **写剧本**（`scripts/gen_script.py`）：产出 `script.md` + `分镜.md`。
   **停下来给用户看**，确认后才继续。
3. **生成旁白**（`scripts/gen_tts.py`）：逐段输出 `音频/NN.mp3`，记录每段时长。
4. **生成配图**：按各段画面描述生成 9:16 竖版图；输出到 `图片/`。
5. **生成动态视频**：以配图为首帧逐段生成 5 秒竖版视频，输出到 `视频/`。
   先只做第 1 段，确认后批量。
6. **去水印裁剪**：图片克隆覆盖水印后中心裁成 9:16（`图片916/`）；
   视频在合成时由 `build_video.py` 自动裁掉底部 110px。
7. **合成成片**（`scripts/build_video.py`）：慢放对齐旁白 → 烧录 ASS 字幕 →
   xfade 叠化串联 → 加片头片尾 → 输出 `成片/<书名>_名著介绍_9x16.mp4`。
8. **自检交付**：抽帧生成九宫格预览图，逐项核对下方检查清单。

## Output Format

Return:

- `script.md` — 完整剧本（含标题、各段情节、人物形象、画面描述、旁白）
- `分镜.md` — 分镜表（画面要点、运镜提示、时间轴、转场包装）
- `音频/NN.mp3` — 旁白
- `图片/NN.png` — 9:16 配图（原图）
- `图片916/NN_916.png` — 去水印裁剪后的成品图
- `视频/NN.mp4` — 动态素材
- `成片/<书名>_名著介绍_9x16.mp4` — 成片
- `_预览_成片九宫格.png` — 抽帧预览，用于快速验收

## Verification（交付前逐条核对）

- [ ] 各张图的画风是否完全一致（油画笔触、色调统一）
- [ ] 主要人物在跨段落中的形象是否对得上
- [ ] 各段画面描述的风格后缀是否逐字相同
- [ ] 字幕文字与旁白是否一致
- [ ] 旁白总时长是否与画面总时长对齐（误差 < 0.3s）
- [ ] 素材水印是否已清除
- [ ] 有没有漏掉转场与片头片尾

## Examples

User: `/magic-realism-novel-video 百年孤独`

Output（已实跑验证）:

- 标题《百年孤独：马孔多的一场大雨》，9 段：开篇回想起 → 作者与诺奖 → 建村
  → 马孔多 → 蕾梅黛丝升天 → 金色蝴蝶 → 四年大雨 → 七代孤独 → 飓风与羊皮卷
- 统一风格：拉美魔幻现实主义油画风格，厚涂笔触，暗金与青灰配色
- 成片 155.5 秒，1080x1920，含旁白、字幕、叠化转场、片头片尾

User: `/magic-realism-novel-video 老人与海`

Output: 同结构 8-9 段（老人出海 → 马林鱼缠斗 → 鲨鱼来袭 → 归港……），
画风后缀换成与海洋题材匹配的统一风格串，`characters` 里写死老人外形。

## 环境依赖

- Python 3.11+，`edge-tts`、`mutagen`、`pillow`、`imageio-ffmpeg`
- 生成式图像/视频能力（内置 ImageGen / VideoGen，或火山方舟豆包 Seedream + Seedance）
- 详细参数与踩坑见 `reference.md`
